# Issue tracker: Linear

Issues and specs for this repo live in Linear, in the
[svenskaapp project](https://linear.app/stepan/project/svenskaapp-de4ec9cad771/overview).

Agents may freely read, create, and update issues in this project.

## Conventions

- Create new work as an issue in the svenskaapp project.
- Read the full issue, including its description, comments, status, labels, and linked work before acting.
- Keep the issue title, description, status, labels, and comments current as the work progresses.
- Use Linear's issue URL or identifier when referring to a ticket.
- Apply the label strings defined in `docs/agents/triage-labels.md`.

## When a skill says "publish to the issue tracker"

Create an issue in the svenskaapp Linear project.

## When a skill says "fetch the relevant ticket"

Open the specified Linear issue and read its full details and activity.
